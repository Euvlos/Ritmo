# Конфиденциальность

Ritmo не требует аккаунта и не отправляет цели, историю выполнения или настройки на сервер разработчика. Данные приложения хранятся локально на устройстве в Room и DataStore.

Android может включать Ritmo в системное резервное копирование в соответствии с настройками устройства. Уведомления и виджет обрабатываются локально. Выбранные пользователем мелодии будильника копируются во внутреннее хранилище приложения и никуда не отправляются. Приложение не содержит рекламных и аналитических SDK.

Для проверки обновлений Ritmo обращается к публичному GitHub API репозитория `Euvlos/Ritmo` и при подтверждении пользователя скачивает APK из GitHub Releases. При этом GitHub получает стандартные сетевые данные запроса, включая IP-адрес и User-Agent приложения. Цели, история выполнения, настройки и мелодии в эти запросы не включаются. Проверка выполняется при запуске приложения и вручную в настройках.

Скачанный APK временно хранится в кэше приложения и передаётся системному установщику Android. Установка всегда требует системного подтверждения пользователя.

При удалении приложения локальные данные удаляются средствами Android, если они не были восстановлены из системной резервной копии.
