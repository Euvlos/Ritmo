# Участие в разработке

1. Создайте issue или найдите существующий.
2. Сделайте fork и отдельную ветку от `main`.
3. Не добавляйте keystore, пароли, токены, APK и настройки IDE.
4. Сохраняйте архитектуру UI → ViewModel → repository → Room.
5. Для новой бизнес-логики добавляйте unit-тесты.
6. Проверьте Docker-сборку и опишите ручную проверку.
7. Создайте небольшой сфокусированный pull request.

Отправляя изменение, вы соглашаетесь распространять вклад на условиях Apache License 2.0.
