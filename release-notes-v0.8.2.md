# Ritmo 0.8.2

Ritmo — приложение для целей и привычек с локальным хранением данных. В этом выпуске переработан виджет: у каждой цели есть собственная строка, прогресс и кнопка выполнения.

Настраивайте расписания и напоминания, отмечайте выполненные и пропущенные цели, следите за календарём и аналитикой. Данные остаются на устройстве.

## Установка

Скачайте `ritmo-release.apk` из файлов релиза и откройте его на устройстве с Android 8.0 или новее. Если Android сообщает о несовпадении подписей, сохраните данные перед удалением старой версии: при удалении приложения локальная история может быть утрачена.
