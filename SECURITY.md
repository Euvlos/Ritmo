# Политика безопасности

Не публикуйте сведения об уязвимости в открытом issue. Используйте GitHub Private Vulnerability Reporting в разделе **Security** репозитория.

Укажите затронутую версию, шаги воспроизведения и возможное влияние. Поддерживаемой считается последняя опубликованная версия. Не отправляйте реальные ключи подписи, пароли, токены или пользовательские базы данных.
