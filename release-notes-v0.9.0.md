# Ritmo 0.9.0

В этом выпуске появилось полноценное редактирование созданных целей: расписание, количество выполнений и параметры напоминаний теперь можно менять без удаления цели и потери истории.

Напоминания получили три режима: тихое уведомление, уведомление с вибрацией и полноэкранный будильник. Для будильника можно выбрать системную мелодию или импортировать аудиофайл с устройства — пользовательские мелодии сохраняются во внутренней библиотеке Ritmo.

Приложение теперь само проверяет GitHub Releases, уведомляет о новой версии и позволяет скачать APK и передать его системному установщику Android прямо из настроек.

## Установка

Скачайте `ritmo-release.apk` из файлов релиза и откройте его на устройстве с Android 8.0 или новее. Обновление поверх предыдущей версии сохраняет локальные данные при условии, что APK подписан тем же ключом.
